# SARATHI submission information

## Link to submit in Google Forms

Paste this repository link into the form:

`https://github.com/BTMC26O1132/sarathi`

Anyone with the link can view the source code and download a ZIP copy using **Code → Download ZIP**.

## What the submission contains

- Secure local sign-in with private student accounts.
- A SQLite database created on the computer running the portal.
- Account-scoped marks, study plans, and one-to-one mentoring chat.
- A mentor-only model-evaluation page with MAE, RMSE, R², and baseline comparison.
- A synthetic starter model clearly identified as a demonstration only.

## How the evaluator can run it

1. Download the repository ZIP from GitHub and extract it.
2. Install Python 3.10 or later.
3. Double-click `start_sarathi.bat`.
4. Open `http://127.0.0.1:8765` if it does not open automatically.

This is a local prototype. It is intentionally not a public hosting deployment and should not be used with real student data without institutional security, privacy, and deployment controls.
